# local-news.json の更新ルール

`frontend/data/local-news.json` は、定期実行のエージェントが毎日 **朝（7時）・昼（12時）・晩（18時）**（日本時間）に更新します。サイトの `/kamo` と トップページに表示されます。

## 集める情報

新潟県と加茂市の、次のような公開情報。

- **イベント**：加茂市・県央（三条・燕・田上・五泉など）・新潟県の祭り、催し、公演
- **季節**：紅葉・桜・雪・旬の味覚の見頃
- **グルメ**：新米・地元の味の催しや話題
- **体験**：参加できる体験・教室
- **話題**：地域の明るいニュース
- **防災**：クマ出没、大雨・大雪への備え、通行止めなど**公的機関（気象庁・新潟県・加茂市・警察）が発表したもの**

## 守ること

1. **出典が確認できるものだけ**を載せる。各項目の `url` は実際に開けるページにする。推測・未確認の日程は書かない（「例年◯月」と書く）。
2. **防災情報は公的機関の発表だけ**。警報・注意報そのものは画面が気象庁のデータを直接表示するので、ここには「注意喚起・備え」を書く。不確かな災害情報は載せない。
3. 終わったイベント（`date` が今日より前）は外す。全体で **8〜12 件**、加茂市の話題を半分以上にする。
4. `updatedAt` は更新した日時（日本時間、ISO 8601）、`slot` は「朝」「昼」「晩」のどれか。
5. 文章は丁寧でやさしい日本語。`summary` は 80 字程度まで。人の実名（公人を除く）や個人が特定できる情報は書かない。
6. 形式は下の通り。`category` は `イベント` `季節` `グルメ` `体験` `話題` `防災` のどれか、`area` は `加茂市` か `新潟県`。

```json
{
  "updatedAt": "2026-10-18T07:00:00+09:00",
  "slot": "朝",
  "items": [
    { "title": "…", "summary": "…", "category": "イベント", "area": "加茂市", "date": "2026-10-25", "source": "加茂市", "url": "https://…" }
  ]
}
```

## 更新後

`cd frontend && npx tsc --noEmit && npx next lint && npx next build` が通ることを確認してから、`feature/lumina-frontend` にコミットしてプッシュし、`main` を fast-forward してプッシュする。fast-forward できないときは force push せずに止める。
